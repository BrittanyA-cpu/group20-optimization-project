# Results

Output tables and figures generated by `notebooks/results_and_sensitivity/ipynb` for a random baseline scenerio of `q_min = 4.2`, `budget = 14000`, and `max_space = 1700`.

## Files
* `optmal_schedule.csv`: Table of selected food trucks, their category, revenue, cost, net profit, space and quality ratings
* `selected_trucks_profit.png`: Bar chart that shows the net profit of each selected truck.
* `budget_sensitivity.png`: Line graph showing how optimal net profit changes as the budget increases or decreases.
